# Smart Text Analyzer & Keyword Extractor

A native, lightweight open-source Python tool designed to automate text analysis, document parsing, and content optimization.

## Features
- **Extractive Summarization:** Uses frequency-distribution scoring to extract the most crucial sentences from long articles or documentation.
- **Keyword Extractor:** Filters out common stopwords to isolate the top 5 most meaningful keywords in any text block.
- **Zero Dependencies:** Built entirely using Python's standard libraries (`re` and `collections`), ensuring zero external requirements.

## How to Run

1. Make sure you have **Python 3.x** installed.
2. Download the `text_analyzer.py` file.
3. Open your terminal or command prompt and run:
   ```bash
   python text_analyzer.py
   ```
4. Paste your long text and press Enter, then press `Ctrl+D` (Linux/Mac) or `Ctrl+Z` then `Enter` (Windows) to get the results.
